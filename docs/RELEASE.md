# 3WA 3D Viewer 20261119.003

- 場景導演可讀取本機宣告式 JSON，讓最多四個 GLB 共用時間軸：獨立移動、自轉、內建動畫、定時 3D 部位註記與字幕、方向光投影，以及鏡頭硬切／短疊化。
- 桌面可載入腳本預覽、播放與拖曳時間軸；MCP `record_director_scene` 只接收核准本機的 `scenePath`，以同一套流程錄製無聲 H.264 MP4（640×480、30 fps、1–20 秒）。
- 模型必須是腳本目錄內的相對 GLB 檔案；不接受 URL、任意程式碼或外部模型資源。MP4 需自備含 libx264 的 FFmpeg，下載包不內附。
- 下載 Windows x64 ZIP，解壓後用 `3wa_3dviewer.exe` 啟動；可用附帶的 SHA-256 核對下載。
